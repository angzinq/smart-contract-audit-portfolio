## nft-marketplace
只保留合约、测试与配置（前端与依赖不入库）。合约实现 NFT 铸造与挂单交易，配套约 11KB 的单元测试覆盖铸造、授权、交易与边界条件。

## cross-chain-identity
方案从跨链身份认证的矛盾出发：系统需要验证身份有效性，用户不希望暴露身份；监管需要可追溯，匿名性又可能被滥用。
用**群签名**做到"能验证属于某群、不能溯源到个人"，纠纷时由群管理员撤销匿名；再用**格密码**替换传统数论假设以抗量子。
