# 02 · Damn Vulnerable DeFi

Damn Vulnerable DeFi 是 DeFi 安全方向的经典靶场，题目直接来自真实协议的漏洞模式。
我完成 **5 关**，其中 **4 关**已整理完整 writeup 入库。

| 关卡 | 攻击类型 | 一句话 |
|---|---|---|
| Dex | 价格操纵 | 恒定乘积定价可被反复换仓拉偏，逐步抽走池内代币 |
| FREEBIE | 奖励逻辑缺陷 | 领取条件与余额检查之间的时序问题 |
| Recovery | 合约自毁与地址复原 | 从交易记录反推被遗忘的合约地址 |
| REVERSE RUGPULL | 后门识别 | 逆向读源码，找出部署者预留的提取后门 |
